# 整段检测研究实验方案

## 假设和主要终点

任务为整段录音二分类。主要假设：在固定专家、观测、开发数据和调参预算下，按机制族共享交互系数的关系融合，相比充分调参的普通线性融合、MLP 和逐专家对交互，在外部语料上减少 EER。主要终点预先选为跨语料的逐数据集 EER；FPR=5% 开发阈值下的召回/FNR 为次要终点。不能在看到测试结果后挑选有利语料、种子或阈值。

## 数据

ASVspoof2019 LA 官方 train/dev 为唯一建模来源。开发角色说话人互斥，测试标签不参与训练或参数选择。首先完成源语料官方 eval，再分别评估 InTheWild、ASVspoof2021 DF/LA、Codecfake 等有明确真假标签的外部数据。单类语料单独报告召回或 FPR，EER/AUROC 不定义，不将它们伪造为零。

不同语料间如存在共享录音、原始说话人或变体，应建立全局映射；相同波形哈希只能覆盖完全相同内容，不能替代近重复与说话人审计。报告排除清单、类别数量、说话人未知比例、短音频补齐比例和每个专家失败比例。

## 对照

运行 17、42、2026 三个种子。固定同一专家输出，比较 `mean/flat_lr/mlp/relation_lr/pairwise_lr`。移除关系特征、移除质量特征及其交互、逐一移除专家，并提供每个单专家的校准结果。主要增量应同时超过普通融合和强非线性/非共享交互对照；只胜过平均分数不足以证明本体的独特价值。

当前三个专家分别归为三个不同机制族，因而只检验异族池化。若要检验同族/异族两种关系的共享，必须引入额外的真实同族专家或预先规定的机制族分组对照，不能仅修改名字制造结论。可增加随机族标签与参数量匹配对照，检验收益是否来自分组先验。

## 校准和解释

专家 checkpoint 由 `expert_select` 的 EER 选择。融合正则化由 `fusion_select` 的 NLL 选择，分数/特征尺度只在 `fusion_train` 拟合。`calibration` 拟合 sigmoid，`threshold` 冻结决策阈值。报告 Brier/NLL 与 risk-coverage；检查 MLP 收敛记录并给各模型合理调参预算。

解释应核对 logit 加性一致性、来源哈希和缺失拒判行为。通过移除专家、遮蔽证据等受控实验检验解释稳定性，而非仅展示几个有利样例。质量与语料条件相关，不能把质量交互归因于真实伪造机制。

## 统计和失败条件

按语料报告每种子结果和种子间波动。使用相同测试录音，对 `relation_lr - flat_lr` 的 EER 差值做配对分组 bootstrap，单位为已知说话人，否则为原始录音。三种子不能当成大量独立样本。差值置信区间覆盖零、改善不稳定、MLP/逐对交互更好或收益只来自质量捷径时，不主张关系先验提高泛化。

当前代码的矩阵与配对 bootstrap 提供执行工具；上述全量研究结果尚未产生。GPU 训练、兼容的 SSL 环境、吞吐测量和研究论文应在取得真实结果后再完成。
