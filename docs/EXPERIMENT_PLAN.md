# 科学问题、实验协议与推进顺序

## 1. 建议课题与可证伪假设

建议题目：**面向局部语音伪造检测的类型化证据融合与可靠性评估**。在结果出现前，不把“本体提高泛化能力”写成既定结论。

研究问题是：固定已有语音专家及其分数，在相同训练数据、质量协变量和时间上下文下，显式表达来源关系、关系类型和缺失状态，是否能改善局部编辑检测的泛化、校准与可审计性？

三个可单独失败的假设：

1. **类型假设**：按同族/异族关系共享成对交互参数，在少量训练数据时比自由学习的融合更稳定。证据族是模型来源先验，不是独立性定理。
2. **条件假设**：实测质量与专家分数的交互，能解释一部分条件变化下的误报；只有在两类都包含对应处理条件时才检验这一点。
3. **来源假设**：明确复制链可使结果对重复测量保持不变。这是可测试的工程性质；仅证明这一点不构成强检测算法创新。

必须允许的否定结果：关系版不优于充分训练的 flat MLP；错误关系不损伤结果；收益仅来自增加非线性特征、优化差异或参数量。出现这些结果时，应把贡献改为证据管理、校准或实验协议，而不能继续宣称本体推理优越。

## 2. 任务定义

本版本针对**录音中存在可标注时间区间的生成式内容替换/插入**。帧标签为编辑区间中点是否落在人工/发布标注内；整句标签为是否包含至少一处内容编辑。默认 40 ms 输出格，专家可有自己的原生格。

纯编码解码处理在“内容编辑检测”这个受控任务中可作为负例，前提是内容与身份未发生目标意义上的修改。它不是所有“AI 处理检测”任务通用的标签约定。不能悄悄修改现成基准的官方标签；新建处理实验应作为独立协议发布。

当前不覆盖只删除原始内容而不产生正时间区间的编辑、整句文字真实性判定、说话人身份授权或原话重建。语音真实性与话语内容事实性是不同的评测目标。

## 3. 数据选择与泄漏控制

### 主实验：PartialEdit v1.1 + 配对 VCTK

[官方 v1.1](https://zenodo.org/records/18829689) 修正时间戳并提供 speaker split。首轮用公开 E1/E2；论文中的 E3/E4 不应当成已公开可复现实验。E1 为 VoiceCraft，E2 为建立在 VoiceCraft 上的 SSR-Speech，因此 E1→E2 最多是有限的编辑器迁移证据，不能被描述为覆盖所有未知生成模型。[论文原文](https://www.isca-archive.org/interspeech_2025/zhang25g_interspeech.pdf)

使用官方 train/dev/eval 的说话人名单，eval 映射 test。仅从 dev 中按说话人留出 calibration；同源的原音频、不同编辑结果和所有处理变体保持同组。后续增广也在固定分组之后生成。

拟合数据的用途固定如下：

| 切分 | 唯一用途 |
|---|---|
| train | 检测器尺度、特征标准化、融合参数、整句汇总头 |
| calibration | 帧与整句分数的 Platt 校准 |
| dev | 选冻结阈值；在正式实验中比较候选超参数 |
| test | 一次冻结报告，不重校准、不挑阈值、不决定删哪些难例 |

对于后续调参，需预先固定搜索空间与预算；反复观察同一 dev 会有开发过拟合风险。最终应留出独立测试或再做预先定义的外部验证。

### 预训练专家的数据污染审计

CFPRF 的 `1FDN_PS.pth` 使用 PartialSpoof 训练背景；PartialSpoof/ASVspoof 与 PartialEdit 的 VCTK 来源有潜在联系。manifest 中的 speaker/source 检查只能验证当前显式给出的分组，不能证明公共预训练 checkpoint 没见过测试原音频。必须记录专家训练来源；来源重叠无法排除时，将实验限定为“固定公开专家在新编辑方式上的迁移/融合”，不声称完全未见语料泛化。

更强验证需要不同源语料的外部测试，或在已审计的不重叠训练子集上重新训练专家。HAD 等其他语料可作为后续候选，但需单独核对语言、说话人、源音频和专家训练重叠，不能仅依据数据集名字不同就认定独立。

### 条件实验必须成对

仅把现有 E1-Codec/E2-Codec 当作正类追加，真实录音全不做处理，会把处理痕迹与正标签混淆。正确的第二阶段协议是：

| 内容 | 无新增处理 | 相同处理流程 |
|---|---|---|
| 真实内容 | 原录音 | 原录音经过同一编码解码链 |
| 含局部编辑 | 编辑录音 | 编辑录音经过同一编码解码链 |

“相同”需要明确 codec/checkpoint、版本、码率、采样率、声道、量化和时间对齐。所有组合使用相同的输入前处理和文件格式。处理参数是审计标签，不直接输入分类器。信道/codec 变化若造成时移，应先验证和修订标签对齐；不能只核对总时长就认为毫秒级定位完全正确。

本交付实现了既有 Codec 文件导入和普通音频重采样，**没有实现神经 codec 增广**。RMS/削波率也不等于 codec 条件估计器。没有完成配对负样本之前，不应报告“codec 条件下低误报提高”。

## 4. 当前最小数值模型

### 输入

每个专家提供原生时间区间上的有方向分数、有效状态和来源。复制关系去重后，在 train 中按观测时长拟合每个专家的分数均值与标准差；推理时固定。概率输入先转 log-odds，这只是数值变换，不意味着已校准。重叠原生区间按时间并集计算覆盖；专家只有完整覆盖某个输出格时，该格的专家值才有效，避免把部分观测末格延长到未观测尾部。覆盖率是这个保守输出网格的覆盖率，不是假定所有毫秒都已得到预测。

记对齐后的标准化分数为 $z_{m,t}$，有效性为 $v_{m,t}\in\{0,1\}$，实测质量为 $q_t$。基础特征包含每个专家的分数、有效性、同一时间范围的局部均值/标准差、质量与质量 mask，以及录音时长。所有模型拿到同样的基础信息。

### 本体如何进入计算

registry 产生两种边集合：同族专家对 $E_{same}$ 和异族专家对 $E_{different}$。对每一种关系 $r$，计算：

$$
P_r(t)=\frac{\sum_{(i,j)\in E_r}v_{i,t}v_{j,t}z_{i,t}z_{j,t}}
{\sum_{(i,j)\in E_r}v_{i,t}v_{j,t}},\qquad
D_r(t)=\frac{\sum_{(i,j)\in E_r}v_{i,t}v_{j,t}|z_{i,t}-z_{j,t}|}
{\sum_{(i,j)\in E_r}v_{i,t}v_{j,t}}.
$$

另保留有效专家对的比例。分母为零时用数值占位与零可用比例，不解释成“检测到零伪造概率”。每种关系只有一组融合系数，从而改变 family 分配会改变实际特征汇总，不能靠改列名字假装使用了本体。乘积项是回归协变量，不是独立概率相乘。

时间项为 $v_{m,t}|z_{m,t}-\overline z_{m,t}|$；条件项为有效分数乘以有测量的质量协变量。之后使用带正则的逻辑回归，再以独立 calibration 拟合一维校准。整句头由局部分数的均值、标准差、最大值、分位数、超固定中值比例、长度和覆盖率训练得到，不使用把重叠帧当独立事件的 noisy-OR。

这是可检查的参数共享与特征设计。RDF 图是审计视图，代码没有读取任意 OWL 规则自动生成神经网络；SHACL 只做结构验证。未来可把相同类型关系用于 CRF/因子图/异构图网络，但必须另写模型、训练和对照。

### 输出边界

局部候选区间由网格分数超过开发阈值后合并而得；整句概率来自另一个校准头，二者没有强制的联合概率一致性。当前不是联合序列解码器。线性特征贡献与证据 ID 支持追踪，但不构成对某个生成器或处理过程的因果归因。

## 5. 对照与消融

| 编号 | 方法/条件 | 目的 |
|---|---|---|
| B0 | 单个真实专家 + 同一校准协议 | 判断多专家是否带来收益 |
| B1 | `mean` | 方向和尺度统一后的等权分数融合 |
| B2 | `flat_lr` | 同一基础信息的线性融合 |
| B3 | `flat_mlp` | 同一基础信息的非线性融合；给足调参和收敛机会 |
| R | `relation_lr` | 按类型共享系数的关系特征融合 |
| A1 | 删除同族块 | 检验这类关系增量 |
| A2 | 删除时间绝对偏离 | 检验显式局部变化特征增量 |
| A3 | 删除质量交互 | 区分质量主效应与条件依赖 |
| A4 | 随机重分 family，保留族大小 | 检验真实关系类型优于任意关系；需多个预注册随机种子 |
| A5 | 加入已确认的测量副本 | 检查预测不变性；当前测试覆盖 |
| A6 | 按预定义概率屏蔽专家/区间 | 测缺失机制变化与覆盖率，不把缺失编码成真实 |

B1–B3 与 R 都保留时间上下文、质量信息、缺失 mask。不能只给 R 音质和时间信息，然后把优势全部归因于“关系”。类型池化减少交互自由度，但完整模型参数量仍与 flat LR 不同，应同时报告维度、参数量与学习曲线。

不能用同一个模型复制三份伪造“多专家”。相同 encoder 的多个 checkpoint 或分辨率可以研究依赖，但应诚实列为同族并测实际错误相关性。两个专家可先检验普通融合；检验本版本的类型共享机制时，建议至少三个专家，同时具有同族/异族关系，并在至少一种关系中存在多个专家对。在正式实验中加入一个真正不同的证据来源，才有较强的互补性论证。

A1–A3 已有配置，A5 已有测试。A4 与 A6 在当前版本属于实验协议，未包装成独立命令；必须记录随机种子、关系分配或缺失 mask 后再运行。不要把修改 `family` 造成特征值变化的单元测试误作 A4 的真实性能结果。

## 6. 指标、置信区间与停止条件

首要建议指标：开发集冻结低误报阈值后的整句召回与实际测试 FPR，同时报告 Brier/NLL。小试验可先用开发 FPR 5%，正式应用再按真实样本量与目标风险定义更低工作点。若只有几十条真实 dev 录音，不能把经验 0 次误报宣称为已经精确估计 0.1% FPR。

当前实现报告：

- 帧级：基于网格中点标签，混淆量按秒加权；开发阈值也采用相同秒权重。
- 整句：EER（ROC 线性插值）、AUROC、AP、固定阈值 precision/recall/FPR/F1、Brier/NLL。
- 覆盖：有局部证据的时间比例、可用录音数；risk–coverage 同时给全量和可用样本条件分母，且使用同一冻结决策阈值。
- 不确定性：按 `source_recording_id` 整组 bootstrap，保留一个源的所有衍生样本。

EER 是描述性测试指标，其交点不是部署阈值。导出候选区间不等于已实现官方区间 mAP 或 SegmentEER/RangeEER。后续报告这些指标时应接入作者评测代码并核对定义，不将本项目的网格 F1 冒充官方定位指标。

当前 bootstrap 是单模型区间。模型差异检验需要对**同一组抽样索引**做配对 bootstrap，并报告差值区间；不能简单看两组独立区间是否重叠。更换随机种子、不同数据份额和编辑条件也应作为预注册实验维度。

## 7. 实际推进顺序

| 阶段 | 交付目标 | 进入下一阶段的条件 |
|---|---|---|
| 0：工程闭环 | 本交付的模拟流程、接口、本体和测试 | 测试通过；清楚哪些输出是模拟 |
| 1：真实单专家 | 小规模 PartialEdit/VCTK + CFPRF 分数缓存 | 实际加载权重、方向与时间格正确；公开失败清单；有真实基线指标 |
| 2：真实多专家 | 至少两个有实际预测差异的专家，四组融合 | 所有方法使用相同信息与切分；比较强基线而非只比平均 |
| 3：关系实验 | 类型/时间/质量消融和错误关系对照 | 增量能归因；负结果同样记录 |
| 4：更强外部验证 | 配对处理条件、未见编辑器、不同源语料 | 不接触测试阈值；审计源语料与预训练重叠 |

阶段 0 已能在普通 CPU 环境运行。阶段 1 的旧版 CFPRF 环境和真实 checkpoint 验证是当前最具体的待办；不应绕过它直接撰写“系统性能提高”的实验结论。
